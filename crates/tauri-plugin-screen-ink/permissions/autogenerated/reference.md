## Default Permission

screen-ink 창(팝오버·설정·섬)이 InkClient 명령을 모두 쓸 수 있게 한다.

#### This default permission set includes the following:

- `allow-get-state`
- `allow-update-setting`
- `allow-preview-shortcut`
- `allow-set-shortcut`
- `allow-reset-shortcut-group`
- `allow-undo`
- `allow-set-hotkeys-enabled`
- `allow-shortcut-capture`
- `allow-save-pdf`
- `allow-system-fonts`
- `allow-debug-input`
- `allow-run`
- `allow-preview-import`
- `allow-apply-import`
- `allow-reset-all`
- `allow-overlay-ready`
- `allow-capture-input`
- `allow-pin-info`
- `allow-pin-action`
- `allow-pin-zoom`
- `allow-draw-ready`
- `allow-draw-finish`
- `allow-draw-restore`
- `allow-draw-export`
- `allow-draw-island`
- `allow-draw-pen-metrics`
- `allow-zoom-input`
- `allow-capture-annotations`
- `allow-capture-commit-annotated`
- `allow-ui-log`
