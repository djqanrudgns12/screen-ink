요약: 슉쇽은 개인정보를 모으지 않고, 어디로도 보내지 않습니다. 화면 캡처와 설정은 사용자의 컴퓨터 안에만 남습니다.

1. 모으는 정보

없습니다. 슉쇽은 계정·이름·이메일·사용 통계·오류 보고·광고 식별자를 모으지 않으며, 개발자에게 아무 정보도 보내지 않습니다.

2. 컴퓨터 안에만 저장되는 것

무엇어디·얼마나
캡처한 이미지사용자가 고른 곳(클립보드 또는 사용자가 정한 폴더)에만 저장됩니다.
설정앱 데이터 폴더의 설정 파일. 사용자가 지우거나 앱을 제거하면 사라집니다.
범위 기록최근에 캡처한 범위의 사각형 좌표와 시각만(이미지·창 제목 없음). 최대 50개, 30일이 지나면 자동으로 지웁니다. 설정에서 끄거나 모두 지울 수 있습니다.
로그동작 기록(창 제목·파일 이름·사용자 이름은 쓰지 않음). 크기를 정해 두고(2MB) 오래된 것부터 지우며, 컴퓨터 밖으로 나가지 않습니다.

3. 화면과 다른 앱을 읽는 일

캡처할 범위를 찾기 위해 캡처하는 순간의 화면, 창의 위치, 화면 요소의 위치(접근성 정보)를 읽습니다. 이 정보는 캡처가 끝나면 메모리에서 버리며 저장하거나 보내지 않습니다. macOS에서는 이를 위해 "화면 기록"·"손쉬운 사용" 권한을 요청합니다.

4. 통신과 업데이트

  • 슉쇽 앱 자체에는 인터넷으로 정보를 보내는 기능이 없습니다.
  • 업데이트 확인과 내려받기는 운영체제(Microsoft Store 또는 Windows 앱 설치 관리자)가 처리하며, 이때는 Microsoft의 개인정보 처리방침이 적용됩니다.
  • 화면 표시에 쓰는 Microsoft Edge WebView2 구성 요소는 Microsoft의 정책에 따라 스스로 업데이트할 수 있습니다.
  • Windows의 클립보드 기록·동기화를 켜 두었다면, 클립보드에 복사한 캡처는 Windows 설정에 따라 처리됩니다.

5. 아동

교실에서 교사가 쓰는 도구입니다. 학생을 포함해 누구의 정보도 모으지 않습니다.

6. 바뀌는 경우

이 방침이 바뀌면 이 페이지와 시행일을 고칩니다. 지난 내용은 변경 이력에서 볼 수 있습니다.

Privacy Policy

Effective 2026-11-26

Summary: ShookShok does not collect personal information and does not send anything anywhere. Captures and settings stay on your computer.

1. Information we collect

None. ShookShok collects no accounts, names, email addresses, usage statistics, crash reports or advertising identifiers, and sends nothing to the developer.

2. Data stored only on your computer

  • Captured images — only where you put them (the clipboard or a folder you choose).
  • Settings — a settings file in the app data folder; removed when you delete it or uninstall the app.
  • Capture history — only the rectangle coordinates and time of recent captures (no images, no window titles), up to 50 entries, deleted automatically after 30 days. It can be turned off or cleared in Settings.
  • Logs — event logs without window titles, file names or user names, size-limited (2 MB) with the oldest removed first, never leaving your computer.

3. Reading the screen and other apps

To find what to capture, ShookShok reads the screen at the moment of capture, window positions and the positions of on-screen elements (accessibility information). This is discarded from memory after the capture and is never stored or sent. On macOS the app asks for Screen Recording and Accessibility permissions for this purpose.

4. Network and updates

  • The ShookShok app itself has no feature that sends information over the internet.
  • Update checks and downloads are handled by the operating system (Microsoft Store or Windows App Installer); Microsoft's privacy statement applies to them.
  • The Microsoft Edge WebView2 component used to draw the interface may update itself under Microsoft's policies.
  • If Windows clipboard history or sync is turned on, captures copied to the clipboard are handled according to your Windows settings.

5. Children

ShookShok is a classroom tool for teachers. It collects no information from anyone, including students.

6. Changes

If this policy changes, this page and its effective date will be updated. Previous versions are in the change history.

7. Contact

Please use the Support page (GitHub Issues).
