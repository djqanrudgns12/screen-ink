# 슉쇽 2차 마스터 플랜 (PRD v2.0) — 2026-11-27

> 한 줄 목표: **처음 쓰는 선생님도 설명서 없이 바로 쓰고, 맥과 Windows 어느 쪽에서도 똑같이 매끄러운 발표 도구.**

- 기준: 브랜치 `feat/foundation`, 1차 PRD [docs/PRD.md](../../PRD.md) v3.0 위에 얹는 2차 요구. 1차 공통 계약(포트, 좌표 = 가상 화면 물리 px·왼쪽 위 원점, `Case`, `InkClient`, `nativeFrame`)은 바꾸지 않고, 새 포트 메서드·클라이언트 메서드는 기본 구현(또는 선택 속성)을 둔다.
- 요구 ID `R2-<영역>-<번호>`, 우선순위 **P0** 이번 묶음 필수 · **P1** 이번 묶음, P0 뒤 · **P2** 다음 묶음.
- 표기: **[완료]** 코드·자동 시험 끝 · **[결정]** 사용자 결정 · **[기본안]** 총괄이 정한 값(사용자가 바꿀 수 있음) · **[확인 필요]** 아직 사실 확인 전.
- 바뀐 점(v1 → v2, 같은 날): 사용자 결정 4건 반영, 요청 9건 추가(색·굵기 슬라이더, OS 맞춤 내용, 텍스트 글꼴, 트레이 전체 화면 버그, 쉬운 말, 글꼴 역할·크기 보정, PDF 쉬운 말, 아이콘·트레이 결정), 총괄 전역 검토로 개선 12건 추가(§7), 디자인 시스템 2.0(§4)·분업·관문·검증을 마스터 플랜 수준으로.

## 2. 원칙

1. **두 OS 동등(R2-OS-0)**: 모든 기능을 맥·Windows 같은 모양으로. 한쪽만 되는 것은 기술상 불가할 때만, §8.5 표에 까닭을 적는다.
2. **그 OS답게(R2-OSFIT-0)**: 기능은 같게, 말·키·위치는 그 OS 관습대로(⌘/Ctrl, 메뉴 막대/작업 표시줄, 시스템 설정/설정, Finder/탐색기).
3. **쉬운 말, 짧게(R2-WORD-0)**: 초보가 아는 말, 핵심만. 버튼 6자·메뉴 12자·섬 제목 16자 안쪽을 목표로.
4. **맥 감성·세련**: 여백·정렬·글자 위계·아이콘 획을 한 규칙으로(§4).
5. **개인정보**: 로그·PDF·사례 파일에 창 제목·파일 이름·사용자 이름 없음(1차 R-LOG-1). 이 컴퓨터 글꼴 목록 같은 정보도 밖으로 내보내지 않는다.
6. **네트워크**: 앱이 HTTP 라이브러리를 들이지 않는다(1차 R-NET-1·2). 자동 업데이트만 OS 통신 기능으로 한 주소(§6.9) **[기본안]**.
7. **분업**: 총괄(Claude) = 설계·계약·핵심 로직·검수. 제미나이(Antigravity 네온 오케스트레이터) = 화면 구현·이식·문자열 옮기기·시험 보강·조사·문서 잡무. 코덱스는 쓰지 않는다 **[결정]**(§8.2).

### 4.1 글꼴 — 역할별 + 크기 보정 (R2-FONT)

| 역할 | 글꼴 | 굵기 | 쓰는 곳 | 까닭 |
|---|---|---|---|---|
| 본문(UI) | **Freesentation** | 400·500·600 | 설정·섬·툴바 이름·첫 실행·설명서 | 폴더 후보 중 유일하게 굵기 4종·한글 11,172자·고정폭 숫자·SIL OFL 1.1 |
| 트레이·제목 | **Paperlogy** | 5Medium·6SemiBold | 트레이 팝오버, 창 제목, 첫 실행 카드 제목, PDF 머리 | 사용자 결정 D3. **한글 2,780자뿐** → 글꼴 목록에서 Freesentation을 바로 뒤에 두어 빠진 글자만 그쪽으로(글자 단위 대체) |

| 영어 화면 | 같은 역할 글꼴 + **관문**: W2에서 영어 화면 스크린숏을 보고 라틴이 약하면 본문만 Pretendard(OFL)로 바꾼다 | — | — | 제미나이 조사: Pretendard가 라틴 최고 |
| 사용자 글자(텍스트 주석) | 고르는 글꼴(§6.12) | — | 캡처·판서 텍스트 | — |

- **크기 보정(R2-FONT-5, 사용자 요청)**: 같은 13 px라도 글꼴마다 보이는 크기가 다르다. 기준 = 지금 IBM Plex Sans KR의 한글 보이는 높이. 글꼴마다 `@font-face`의 `size-adjust`·`ascent-override`·`descent-override`·`line-gap-override`로 **보이는 높이·줄 높이를 기준에 맞춘다** → 화면의 모든 px 값은 그대로 두고 글꼴만 바꿔도 크기가 어긋나지 않는다. 보정 값은 제미나이 측정(`research/font-metrics.json`)에서 옮겨 `tokens.css` 한 곳에. 두 OS 웹뷰(WKWebView macOS 14+·WebView2) 모두 지원.
- **글자 크기 표(R2-FONT-4)**: 11(보조)·12(메뉴 보조)·13(본문·메뉴)·15(묶음 제목)·20(창 제목) — 보정 뒤 같은 표를 모든 글꼴이 쓴다. 한글 자간 −0.2~−0.4%, 줄 높이 본문 1.45·제목 1.25.
- **부분 집합(R2-FONT-3)**: woff2를 "KS X 1001 2,350자 + 카탈로그(ko·en)에 쓰인 모든 글자"로 줄인다(앱 이름 **"슉"(U+C289)은 2,350자 밖**이라 반드시 넣는다). 사용자가 치는 칸(텍스트 주석·파일 이름 틀)은 전체 글꼴 또는 시스템 글꼴. 빌드 검사: 카탈로그 글자가 모두 들어 있는지. 앱 크기 +2 MB 이하.
- **라이선스(R2-FONT-2)**: Freesentation·Paperlogy·IBM Plex·Pretendard 모두 SIL OFL 1.1 → 앱 번들·PDF 임베딩 가능, 설정 › 정보에 고지. Eulyoo1945(임베딩 금지)·Bookk(수정 금지)는 쓰지 않는다.

### 4.3 색·모양·움직임
- **주석 색(R2-ANN-1)**: §6.11.
- 표면: 맥 = 흐린 반투명(vibrancy) 다크 알약·카드, Windows = 같은 색 계열의 Mica 느낌. 반지름 카드 12·알약 999·단추 8, 그림자 한 벌, 1 px 안쪽 테두리.
- 움직임: 120~180 ms, ease-out. **"동작 줄이기"(OS 설정)를 따르면 즉시 전환**(R2-A11Y-3).
- 다크·라이트·시스템, 대비 4.5:1 이상(글자), 3:1 이상(아이콘·테두리) — 자동 검사(1차 0.4b 미완 항목을 여기서 닫는다).

### 4.4 말(카피) 규칙 (R2-WORD)
- 용어집 = 제미나이 [research/terms-audit.md](research/terms-audit.md)(작성 중)를 총괄이 확정 → `docs/brand/용어집.md`. 화면 글은 카탈로그(§6.2)에만 있고, 카탈로그 검사가 용어집 밖 낱말(예: "판서·오버레이·근거·전역·아일랜드")을 막는다.

| F10 글꼴 고르기 | 계약(글꼴 목록 포트·굽기 순서) | Tidy식 패널 이식 | complex |
| F11 PDF | 생성 포트·OS PDF 호출·저장 | 시안 4 이식·쉬운 말·영어·쪽 넘김 | complex |
| F12 업데이트 | Sparkle 연동·서명·릴리스 스크립트 | 시트·설정 묶음·시험 | standard |
| F13 스마트 캡처 | 알고리즘·순수 함수 | 합성 사례·벤치·회귀 표 | standard |
| F14 품질 | 성능 예산·관문 판정 | 스냅숏 시험(QA-1)·접근성 검사·동등 표 뽑기 | standard |

**맡기기 규칙(브리지 운영)**
- 한 번에 제미나이 3~4칸(칸 4개), 같은 파일을 두 일이 동시에 고치지 않게 **파일 소유표**를 맡길 때마다 적는다(예: F3 화면 설정 갈래 = `screens/SettingsWindow.svelte`·`GeneralPage.svelte`…만).
- 본문에 작업 폴더·목표·완료 기준·고칠 파일·검사 명령·커밋 방법(`git commit --only -- <경로>`)·"한국어로 보고"를 적는다.
- 받은 결과는 diff 훑기 + 바뀐 범위 검사 한 번 + 눈 검수(화면 일은 스크린숏). 지어낼 수 있는 값(해시·수치)만 대조.
- 같은 작업 트리를 쓰므로 `git pull --rebase`는 남의 올려 둔 파일이 있으면 실패 → 총괄은 `git commit --only`로 커밋하고 앞설 때만 밀어 넣는다.

### 8.3 사람이 할 일(에이전트가 못 함)
1. 맥 권한 켜기(첫 실행 카드에서 직접).
2. 트레이 버그 실기 한 번: 설정 창을 연 채 전체 화면 앱에서 메뉴 막대 슉쇽 클릭(계측 판 설치 뒤).
3. Sparkle EdDSA 키 만들기 + Bitwarden `ops` 백업, 자체 서명 인증서 p12 Bitwarden 백업.
4. 릴리스 초안 → 공개 확인.
5. 새 사용자 3명 관찰(성공 지표 §1).
