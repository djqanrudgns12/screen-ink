## (나) 말투 규칙 (핵심 8줄)

1. **짧은 존댓말 `~해요`로 통일**: `~하세요`·`~세요`·반말을 쓰지 않는다. *(예: `키를 누르세요` → `새 키를 눌러요`, `고르세요.` → `골라요`)*
2. **한 줄 안내·오류 끝 마침표 금지**: 버튼·배너·섬·시트 설명 한 줄에는 마침표(`.`)를 붙이지 않는다. *(예: `지금 설정과 내용이 같아요.` → `지금 설정과 같아요`)*
3. **한 뜻 한 낱말**: 동의어를 섞지 않는다. *(예: `되돌리기`·`다시 하기`, `기본값`, `화면에 고정`, `방금/이전`으로 고정)*
4. **동작 중심으로 짧게**: 내부 구조·개발 용어 대신 사용자가 얻는 결과를 말한다. *(예: `클립보드를 쓸 수 없어요` → `복사하지 못했어요`, `끝나지 않은 녹화` → `저장 못 한 녹화`)*
5. **내부 말·로드맵 노출 금지**: `알약`·`후속`·`1차/2차`·`이 PC에서`·`screen-ink` 같은 작업자 언어를 화면에 쓰지 않는다. *(예: `후속` → `준비 중`)*
6. **길이 예산 준수**: 버튼 **6자**, 메뉴 한 줄 **12자**, 섬 제목 **16자**, 섬 보조 **24자** 안쪽을 지키고, 넘으면 제목과 보조로 나눈다. *(예: `단축키를 켰어요 · {n}개는 다른 앱이 쓰고 있어요` 29자 → `단축키 켜짐 · {n}개 겹침` 13자)*
7. **OS 말은 OS에 맞게 분기**: `Ctrl`/`⌘`, `Alt`/`⌥`, `작업 표시줄`/`메뉴 막대`, `설정`/`시스템 설정`, `.exe`/앱 이름을 절대 한쪽 OS로 박지 않는다.
8. **영어는 짧은 문장형(sentence case)**: 첫 글자와 고유명사만 대문자로 쓰고 동사·명사 1~3단어로 압축한다. *(예: `Snap to edges`, `Open last drawing`, `Draw & zoom`)*

## (마) 길이 기준 초과 요약 및 `확인 필요` 결정 묶음

### 길이 기준 점검 결과 (`terms-replacements.csv` 반영 후)
- **버튼 (목표 ≤6자)**: 기존 초과 8종(`화면 기록 켜기` 8자, `켰으면 다시 시작` 9자, `단축키 바꾸기` 7자, `물어보고 바꾸기` 8자, `마우스 위치대로` 8자, `가운데로 부드럽게` 9자, `가운데로 바로` 7자, 칩 `요소까지 잡기 · 손쉬운 사용 켜기` 19자) 중 **7종을 6자 안쪽**으로 줄였다. 칩 버튼 `세부 인식 켜기`(8자, 공백 제외 6자)와 색 코드 칩 `{hex} 복사`는 맥락·고유 코드 길이 때문에 예외로 표시했다.
- **메뉴 한 줄·단축키 이름 (목표 ≤12자)**: 기존 초과 4종(`창 ↔ UI 요소 찾기 전환` 15자, `빠른 저장(묻지 않고 저장 폴더로)` 19자, `화면 강조(스포트라이트)` 13자, `번호 도장(1, 2, 3…)` 15자)을 **전원 10자 안쪽**으로 줄였다.
- **섬 제목 (목표 ≤16자) · 보조 (목표 ≤24자)**: 기존 17~29자 섬 제목 **22종**을 16자 안쪽으로 줄이거나, 접두 결합(`record.rs` `{prefix}{place}녹화를 저장했어요` 최대 28자)을 `제목(≤16자) + 보조(≤24자)` 구조로 분리하는 안을 냈다.

### `확인 필요` 107행 → 핵심 의사결정 7건
CSV의 `확인 필요` 107행은 아래 7가지 방향만 정하면 일괄 확정할 수 있다(합계 107행).
1. **`판서` → `화면 그리기`/`그리기`** *(49행, 스토어 설명·검색어 포함)*: 일반 발표자·초보자 범용성 vs 교사층 친숙도(스토어 검색어엔 `판서` 병기 권장).
2. **`모서리 자석` → `경계 자동 맞춤`** *(7행)*: 기능 직관성 vs 친근한 자석 비유.
3. **`배율` → `확대 크기`(줌) / `화면 비율`(모니터)** *(9행)*: 줌·DPI 혼용 해소 vs `×2.0 배율` 익숙도.
4. **`클립보드` → `복사` · `(코덱)` 생략 · `보안 화면` → `보호된 화면`** *(16행, 중복 항목 제외)*: 초보자 친화 단순화 vs 기술 원인·UAC/DRM 구분 필요성.
5. **`한글·PPT에 {paste}` → `문서·발표에 {paste}`** *(6행, 스토어 `whatsNew`·`shortDescFirst`의 `~습니다` 말투 포함)*: 한국어 교사 맞춤 표현 유지 vs 맥·일반 발표자 범용화(영어는 무조건 `Paste with {paste}`).
6. **OS·타사 공식 명칭 쉬운 말 병기** *(9행 — `내레이터`, `스냅 레이아웃`, `입력 소스`, `스포트라이트`, `텍스트 추출`, ZoomIt `파노라마`/`미러`)*: 초보자용 쉬운 말 병기 vs 공식 명칭 단독 표기.
7. **기타 표기·코드 연동 확인** *(11행 — `찰떡쌤` 영문 표기 `ChaltteokSsaem` 3행, `app.exe`/`.exe` macOS 검증 2행, 패키징 버전 오류 3행, 칩 `세부 인식 켜기` 1행, 경로 `조각` 1행, 스토어 `HEX` 1행)*.
