환경과 준비:
1. 측정 전 `C:\agents\status.ps1`로 다른 작업이 빌드·실행 중이 아닌 **단독 상태**임을 확인한다.
2. 현재 `origin/feat/foundation` 소스로 릴리스 빌드(`npm.cmd run app:build -- --no-bundle` 또는 `npm.cmd run tauri -w @screen-ink/app -- build --no-bundle`)를 만들고, 실행 파일 및 리소스를 `C:\agents\runs\W27-win-measure\app\`에 복사한다. 기준 커밋 해시와 실행 파일 SHA-256을 기록한다.
3. `C:\agents\runs\W27-win-measure\app\`에서 `Shookshok.portable` 포터블 설정(전용 WebView2 프로필, 온보딩 완료, 자동 시작·업데이트 끔)으로 실행한다. Snipaste가 `F1`·`F3`을 쥐고 있으므로 **시험 사본의 포터블 설정에서만** 영역 캡처를 `Ctrl+Alt+F1`, 녹화를 `Ctrl+Alt+F3`으로 바꿔 쓴다(W24와 동일). `Alt+1`·`Ctrl+C`·`Ctrl+S` 등 나머지 단축키는 기본값을 유지한다.
4. 시험 배경은 개인정보가 없는 단색/격자 시험 HTML 또는 빈 메모장(W5·W7·W20 방식)만 띄우고, 측정 후 임시 파일·시험 저장 폴더·시험 창을 모두 정리한다.

할 일:
1. (`2.2`·`R-win-regress`) **60분 대기 뒤 첫 진입 및 20회 회귀**
   - 포터블 앱을 새 프로세스로 띄워 준비 로그를 확인한 뒤 **60분(3,600초) 동안 아무 입력 없이** 둔다.
   - 대기 중 `bench/sample-process.ps1` 방식으로 앱 본체 + WebView2 자식 프로세스의 **합산 작업 집합(MiB)·전용 메모리(MiB)·핸들·프로세스 수·CPU(%)**를 **10분마다(0·10·20·30·40·50·60분)** 기록한다.
   - 60분 대기 직후 아래 순서로 진입을 측정한다:
     - **4K(주, DISPLAY2, 0,0, 200%)** 시험 창 위에 커서를 미리 두고 첫 캡처 진입 1회(`Ctrl+Alt+F1` + 커서 이동) → `overlay ready`(ms), 준비→첫 후보 강조(ms), 단축키→첫 후보 강조(ms), 검은 화면 여부(W5/W23 방식 물리 좌표 기준점 표본 검사로 양쪽 오버레이 확인).
     - **FHD(오른쪽, DISPLAY1, 3840,0, 100%)** 시험 창 위에 커서를 미리 두고 첫 캡처 진입 1회(`Ctrl+Alt+F1` + 커서 이동) → 동일 항목 기록(4K가 60분 대기 직후 최최초 1회임을 명시하고 모니터별 첫 진입을 구분 기록).
     - 이어서 모니터마다 **20회 캡처 진입**(4K 20회, FHD 20회, `bench/m1-overlay.ps1`·W20 방식)을 실행해 `overlay ready` 중앙값·p90·p95·최대, 준비→첫 후보 강조 중앙값·p95·최대, 검은 화면 횟수를 집계한다.
   - 목표: 대기 뒤 첫 진입 `overlay ready` ≤ 150 ms, 20회 진입 p95 ≤ 150 ms, 검은 화면 0(첫 강조는 회귀 대조 참고: ≤ 30 ms).

2. (`4.7`) **4K 판서 복사·저장 멈칫**
   - 주 4K 모니터(3840×2160) 위에서 그리기(`Alt+1`)에 진입해 펜으로 획 몇 개(예: 3~5획)를 그린다.
   - 그 상태에서 **복사(`Ctrl+C`) 10회**와 **저장(`Ctrl+S`, 시험 폴더 지정) 10회**를 각각 실행한다.
   - 매 실행 동안 앱의 모든 최상위 창에 `SendMessageTimeout(WM_NULL, 100 ms)`를 16 ms 간격으로 보내는 `bench/recog/rb20-watch.ps1` 방식으로 **UI 스레드 메시지 루프 응답 시간**(표본 수, p95, 최대, 100 ms 초과 횟수, 시간 초과·호출 실패 횟수)을 잰다.
   - 각 회차의 클립보드 복사 성공 여부·해상도(3840×2160 DIB 확인)와 저장 PNG 생성·파일 크기(바이트·MiB)·해상도를 확인해 기록한다(가능하면 복사·저장 완료 소요 시간도 참고로 병기한다).
   - 목표: 복사 10회·저장 10회 모두 **UI 멈춤 ≤ 100 ms**(100 ms 초과 0회, 시간 초과·실패 0회).

3. **기록 및 정리**
   - 측정 종료 후 `C:\agents\status.ps1`로 측정 중 단독 상태가 유지됐는지 다시 확인한다.
   - 목표에 못 닿은 항목이 있으면 **코드를 고치지 말고**, 앱 로그·계측 근거와 원인 가설만 문서에 적는다.
   - 띄운 앱 사본·시험 창·임시 스크립트·저장 PNG·스크린숏을 모두 정리한다.
