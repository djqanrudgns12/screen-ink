# screen-ink PRD v0.2 — 1차 프로토타입

2026-11-25 · 상태: **초안(검토 대기)** · 작성: Claude(Opus 5.5)
바탕: [아이디어-고도화-1차](아이디어-고도화-1차.md) 13절(v0.1, 2026-11-24 결정) + [벤치마크](benchmark/README.md)(Snipaste 2.11.3 · 아이캔 줌잇 0.7.2.2 · ZoomIt 0.94.1 실측·정적 분석) + [오픈소스·커뮤니티 조사](research/04-oss-benchmark.md)(Antigravity 조사 52개 · Claude 로컬 검증 29개 저장소)

**v0.1 → v0.2에서 바뀐 것**

- 느낌 목표("0.15초 이내")를 **벤치마크 기준값이 붙은 측정 목표**로 바꿨다(5절).
- 기능마다 **요구사항 ID와 합격 기준**을 붙였다(4절). 근거가 된 벤치마크 문서를 함께 적는다.
- 벤치마크로 새로 나온 요구사항: 캡처 먼저·표시 나중 순서, DWM 창 경계·응답 없는 창 건너뛰기, 확대경 색 복사, 직전 판서 되살리기, `RegisterHotKey` 방식, **Snipaste와 F1 충돌 처리**, 보안 데스크톱·절전 처리, 학교망 SSL 차단을 전제로 한 네트워크 0, 로그에 창 제목을 남기지 않기, 벤치마크용 계측 로그.
- 기술 결정에 근거를 붙였다(6절): Windows 실시간 확대 1안 = Magnification API(아이캔 줌잇이 쓰는 검증된 경로), DPI = Per-Monitor V2(ZoomIt과 같음, 아이캔 줌잇의 약점).

## 1. 목적과 사용자

- **한 줄**: 발표자가 단축키 하나로 화면을 캡처하고, 확대하고, 그 위에 쓰는 오프라인 트레이 앱. Snipaste의 캡처 정확도와 아이캔 줌잇의 판서 손맛을 한 앱으로.
- **1차 사용자**: 발표자(교사 포함). 키보드·마우스 중심, 듀얼 모니터(교탁 + TV/전자칠판), 학교 PC(표준 사용자, 학교망).
- **성공 기준(1차)**: ① 5절 성능 목표를 학교 PC에서 통과 ② 6절 시나리오 카드 S1~S15 중 1차 범위 항목 전부 ○ ③ 발표자 3명이 10분 수업 시연을 다른 앱 없이 끝냄.

## 3. 핵심 사용 장면

1. **문제 풀이**: PPT 슬라이드 쇼 중 Alt+1 → 휠로 문제 부분 확대 → 빨간 펜(R)으로 풀이 → Esc. 다음 장으로 넘겼다가 "아까 그거" → Alt+1 후 직전 판서 불러오기.
2. **자료 공유**: 교재 PDF에서 F1 → 커서 아래 표가 자동 강조 → 클릭 → 한글(HWP)에 Ctrl+V. 범위가 마음에 안 들면 F1 후 "직전 범위"로 다시.
3. **시연 녹화**: F3 → 모니터 클릭 → 프로그램 사용법 시연(필요할 때 Alt+1로 표시) → F3 → MP4가 저장 폴더에.

## 4. 기능 요구사항

우선순위: **P0** = 1차 합격에 필수 · **P1** = 1차 안에 하면 좋음(일정 남으면). 근거: SP = [Snipaste 분석](benchmark/snipaste-2.11.3.md), IZ = [아이캔 줌잇 분석](benchmark/icanzoomit-0.7.2.2.md), ZI = [ZoomIt 분석](benchmark/zoomit-powertoys-0.94.1.md), v0.1 = 아이디어 13절.

## 10. 열린 질문

1. **F1 기본값**: Snipaste를 계속 함께 쓸 것인가? 함께 쓴다면 F1 대신 다른 기본값(예: Ctrl+Shift+1)으로 바꿀지, F1을 유지하고 R-KEY-2 안내로 처리할지.
2. 터치용 미니 툴바(아이캔 줌잇 호버 툴바 대응)를 1차 P1으로 올릴지 — 전자칠판에서 키보드 없이 쓰는 발표자가 있는지.
3. 직전 판서 보존을 1장에서 여러 장(판서 기록)으로 늘릴지.
4. ~~오픈소스 조사 결과로 녹화·실시간 확대 구현 경로를 바꿀지~~ → **바꾸지 않음**: ZoomIt(MIT)과 `windows-capture`(MIT)가 같은 경로(Magnification API · WGC + `MediaTranscoder`)임을 소스로 확인([04-oss-benchmark](research/04-oss-benchmark.md) 3절).
5. 판서를 남긴 채 클릭 통과(markeron `Preserved` 모드, 아이캔 줌잇 사용자 최다 질문)를 1차 P1으로 당길지 — 구현 힌트는 확보(04 3절).
