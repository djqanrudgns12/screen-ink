## 1. 공통 규칙

1. **개인정보 보호 · 스크린숏 규칙**
   - 스크린숏은 반드시 **아래 시험 내용(`T1`~`T4`)만 띄운 깨끗한 화면**에서 찍는다(메신저·이메일·업무 문서·실제 창 제목·계정명이 보이는 화면 촬영 금지).
   - 판정 기록을 마친 **임시 스크린숏은 즉시 삭제**한다.
   - **공개 저장소에 그림 파일을 올리지 않는다**(스토어용 등 공개 그림은 총괄이 직접 확인한 것만 별도 절차로 올린다).
2. **한국어 · 영어 두 번 확인**
   - 모든 화면·팝오버·섬·설명서·도구 막대는 한국어(`ko`)에서 먼저 확인한 뒤, **설정 › 일반 › 언어**에서 `English`로 전환해 **재시작 없이 즉시 반영**되는지, 영어 문구 잘림(말줄임 `…`)·넘침·겹침·OS 표기 섞임이 없는지 한 번 더 확인한다.
   - 확인이 끝나면 다시 `한국어`로 되돌린다.
3. **두 OS 분리 원칙**
   - `⌘`/`⌥`/`⇧`/`⌃`, `fn+F1~F3`, `메뉴 막대`, `시스템 설정`, `Finder` (macOS)와 `Ctrl`/`Alt`/`Shift`/`Win`, `작업 표시줄`, `Windows 설정`, `탐색기` (Windows)처럼 다르게 보여야 하는 곳은 표에서 칸을 나누어 확인한다. 교차 표기 섞임이 1건이라도 보이면 `결함`으로 판정한다.
4. **단축키 기준**
   - 여는 방법은 [단축키 확정본 v1](../../shortcuts/README.md) 및 [defaults-v1.json](../../shortcuts/defaults-v1.json)의 기본값을 기준으로 적었다.
   - macOS에서 시스템 설정의 '표준 기능 키'가 꺼져 있으면 `F1`·`F2`·`F3` 대신 `fn+F1`·`fn+F2`·`fn+F3`을 누른다.
5. **판정 기호**
   - `통과` · `결함 (원인/임시 메모)` · `N/A (타 OS 전용)` · `미실행`

### 사전 준비 시험 내용 (`T1`~`T4`)

| 코드 | 띄울 시험 내용 | 준비 방법 |
|---|---|---|
| `T1` | 빈 문서 (텍스트 편집기) | macOS `텍스트 편집기(TextEdit)` 또는 Windows `메모장`에 빈 문서(글자 도구 시험 시 `"가나다 Abc 123"` 1줄만) 띄움 |
| `T2` | 시험 HTML (`rb14.html` 등) | 표 · 버튼 · 여백이 있는 그림 · 둥근 모서리 그림 · 스크롤 영역이 포함된 로컬 시험 HTML(개인정보 0) |
| `T3` | 단색 HTML | 단색 사각형(예: `#476381`, 200×120 이상) 하나만 있는 로컬 HTML (`3e-chip` 확인용) |
| `T4` | 겹친 창 · 다중 모니터 배치 | `T1` 창으로 `T2` 그림 위 약 15%를 가린 배치(`R2-CAP`). 듀얼/혼합 배율 모니터가 연결돼 있으면 두 모니터에 걸쳐 배치(`7.7`·`4.9`·`5.5`) |
