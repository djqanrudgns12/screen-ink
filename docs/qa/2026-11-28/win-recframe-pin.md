# Windows 창 녹화 꺾쇠와 고정 해제 안내

[PRD 3차 §5.1](../../plans/2026-11-28/PRD-3차-마무리.md)의 `6.4`와 `6.5.3`을 확인했다. Windows 11 빌드 26200, 주 화면 3840×2160(200%), 오른쪽 화면 1920×1080(100%)에서 실행했다. 앱 식별자를 시험용으로 지정해 빌드한 뒤 `C:\agents\runs\W22-recframe-pin\app\screen-ink.exe` 사본을 띄웠다. 설정과 영상은 시험 폴더를 사용했다.

## 녹화 꺾쇠

움직이는 도형을 그리는 별도 시험 창을 창 추적 녹화 대상으로 골랐다. 대상 창의 DWM 물리 경계와 꺾쇠 화면의 네 모서리를 비교했다. 스크린숏은 꺾쇠 웹뷰에서만 찍고, 빨간 선의 중심을 웹뷰의 실제 물리 위치에 맞춰 쟀다.

| 시나리오 | 결과 |
| --- | --- |
| 녹화 시작 | 통과. 네 모서리에 표시, 최대 오차 0 px |
| 이동 1~3회 | 통과. 주 화면 안에서 각각 최대 오차 0 px |
| 이동 4회 | 통과. 두 화면에 걸친 상태에서 네 모서리 표시, 최대 오차 0 px |
| 이동 5회 | 통과. 오른쪽 화면으로 이동, 최대 오차 0.5 px |
| 크기 변경 3회 | 통과. 줄임·늘림·다시 줄임에서 각각 최대 오차 0.5 px |
| 최소화 / 복원 | 통과. 녹화 유지, 최소화 동안 꺾쇠 숨김, 복원 후 최대 오차 0.5 px |
| 다른 가상 데스크톱으로 이동 / 복귀 | 통과. 시험 창만 임시 가상 데스크톱으로 이동해 DWM 숨김 값 `2`와 꺾쇠 숨김 확인. 녹화 유지, 복귀 후 최대 오차 0 px. 시험 데스크톱 정리 완료 |
| 녹화 중지와 저장 | 통과. 중지 뒤 꺾쇠 숨김. 두 MP4 모두 H.264 778×448, 이동·크기·복원 76프레임과 가상 데스크톱 왕복 44프레임을 `ffmpeg -xerror`로 끝까지 디코딩 |

## 창 고정 해제 안내

`Alt+Shift+D`로 시험 창을 고정했다. `taskkill /F` 전에는 PID가 위 시험 사본의 경로인지 확인했다. 재실행마다 섬 창의 표시 여부와 문구를 5초 동안 확인했다.

| 시나리오 | 결과 |
| --- | --- |
| 고정 상태에서 강제 종료 → 재실행 | 통과. 시험 창의 고정이 해제되고 “창 고정이 풀렸어요”가 1회 표시됨 |
| 고정 상태에서 정상 종료 → 재실행 | 통과. 종료 코드 0, 시험 창 고정 해제, 재실행 안내 0회 |
| 모두 풀기 → 강제 종료 → 재실행 | 통과. 모두 풀기 즉시 고정 해제, 재실행 안내 0회 |

시험 창과 앱 사본을 닫고 스크린숏을 삭제했다. macOS 실기 및 기본 실행에서 제외된 `#[ignore]` 시험은 미실행이다.

Rust 시험은 지정한 3개 크레이트와 `ink-platform-fake`에서 229개를 통과했고, Clippy의 `-D warnings` 검사도 통과했다. `npm test`는 281개를 통과했으며 `npm run i18n:check`에서 두 언어 1,351개 키를 확인했다.
