# 단축키 확정본 v1

2026-11-25 확정 · 사용자가 [단축키 입력표](shortcut-picker.html)에서 정한 값 + 비워 둔 전역 10칸은 Claude가 채우고 사용자가 확정. 기계가 읽는 기본값은 [defaults-v1.json](defaults-v1.json)(앱의 `ink-domain::shortcuts::DEFAULTS`가 이 파일에서 만들어진다).

- 이 표는 **처음 값**이다. 모든 칸은 **설정 > 단축키**에서 바꾸고, 비우고, 기본값으로 되돌릴 수 있다(PRD R-KEY-3·R-KEY-5).
- 겹침 판정은 입력표와 같은 규칙을 앱 안에서 그대로 쓴다: 운영체제 예약·한/영 키 = 막힘, 다른 앱 기능 = 주의, Snipaste·아이캔 줌잇·ZoomIt = 대체(그 앱을 계속 쓰면 막힘), 같은 화면 안 중복 = 막힘.
- 외우는 법(전역):
  - **F1·F2·F3** = 캡처·창·녹화. F1·F2에 **Shift = 고르지 않고 바로**, **Ctrl = 모니터 전체**, **Alt = 몇 초 뒤**.
  - **Alt+숫자** = 화면 모드(1 판서 · 2 실시간 확대 · 3 칠판 · 4 타이머). **Alt+Shift+1** = 직전 판서 다시 열기. **Alt+`**(숫자 줄 맨 왼쪽) = 단축키 전체 켜기·끄기.
  - **Alt+Shift+글자** = 창·핀(D 창 항상 위 · V 붙이기 · H 숨기기).
- 맥은 같은 자리 키(Ctrl → ⌘, Alt → ⌥)를 기본으로 하되, macOS가 먼저 쓰는 ⌘F1(미러링)은 피했다. 맥 F키는 fn을 함께 눌러야 하고, ⌥ 조합은 그 키로 치던 특수 문자를 못 치게 된다(주의). **창 항상 위 고정은 Windows만**.
- 이 PC 시험(2026-11-25): 전역 16개 중 Windows 조합을 `RegisterHotKey`로 등록해 보니 다른 앱이 먼저 잡은 키 0개(그 시각 Snipaste 꺼짐). PowerToys는 저수준 훅이라 이 시험으로 보이지 않으므로 R-KEY-2가 설정 파일로 따로 확인한다.

### 실시간 확대 화면 안
