# 01. 기능 목록 — Snipaste · 아이캔 줌잇 → screen-ink 결정

2026-11-25 · PRD v3.0 부속 · **기능(동작)만** 본다. 두 앱의 화면 모양·배치·문구는 가져오지 않는다(화면은 Tidy-Task-Local 디자인, [04-screens](04-screens.md)).
출처: 사용자가 보낸 화면 캡처(Snipaste 트레이 메뉴·설정 8장, 아이캔 줌잇 설정 7장), Snipaste 공식 문서 원문(`docs.snipaste.com/wiki/*.md`: Getting-Started · Key-Bindings · Advanced-Tips · Advanced-Configs · Command-Line-Options · PRO), 아이캔 줌잇 `단축키.pdf`, [벤치마크 분석](../benchmark/README.md).

결정 표기: **1차** = 이번 프로토타입 · **P1** = 1차 안에 여유 있으면 · **후속** = 2차 이후 · **안 함** = 범위 밖(이유 적음). 오른쪽 끝 칸은 PRD 요구사항 ID.

## 4. 핀(붙이기) — 1차 범위 밖, 구조만 남김

Snipaste의 핵심이지만 1차 사용자(발표자) 범위 밖이라 **후속**이다. 다만 데이터 모델과 창 구조가 캡처·판서와 겹치므로 [03-architecture](03-architecture.md)에 자리를 남긴다: 이미지·텍스트·HTML·색 카드 핀, 회전 1/2 · 뒤집기 3/4 · 휠 크기 · Ctrl+휠 투명도 · 클릭 통과 토글 · 썸네일 · 닫은 핀 되살리기(최대 개수) · Shift+Esc 완전 삭제 · 그룹 · 모두 숨기기 · 가장자리 자석(20px) · 시작할 때 복원.
