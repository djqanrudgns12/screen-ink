# 05. CRUD 세부 계획

2026-11-25 · PRD v3.0 부속 · 앱이 만들고(Create) · 읽고(Read) · 바꾸고(Update) · 지우는(Delete) 모든 데이터를 빠짐없이 적는다. 각 줄에 **언제(계기) · 검증 · 저장 · 함께 일어나는 일 · 화면 반응 · 되돌리기 · 실패 처리**를 둔다.

공통 규칙:
- **저장 방식**(Tidy `scores.rs` 패턴): JSON 파일 하나에 `{ "schemaVersion": 3, "sections": { "<이름>": { "revision": n, "data": {...} } } }`. 쓰기는 임시 파일 → fsync → 이름 바꾸기(원자적). 직렬 쓰기 큐(Tidy `serialQueue.js`와 같은 생각)로 한 번에 하나씩. revision이 다르면 CONFLICT(다른 창이 먼저 고침) → 최신을 다시 읽고 병합.
- **위치**: 포터블 = `<실행 파일 폴더>\data\`, 설치 = `%APPDATA%\screen-ink\`, Tidy 안 = Tidy 저장 파일의 `screen-ink` 구역.
- **MSIX 패키지**: 패키지 모드에서는 포터블 표시 파일을 무시하고 가상화된 설정·로그 경로를 쓰며, MSIX 제거 시 가상화된 설정·로그도 함께 지워짐([11-distribution](11-distribution.md) §5).
- **백업**: 시작할 때와 5분마다 `settings.json.bak` 교대. 새 파일이 이전의 절반 이하로 줄면 백업을 덮지 않는다(Tidy `lib.rs` 규칙).
- **손상**: 읽기 실패 → 원본을 `settings.json.broken-<시각>`으로 보관 → 백업으로 복구 → 그것도 실패하면 기본값 + 말풍선 "설정 파일이 손상돼 처음 값으로 시작했어요(원본은 보관했어요)".
- **더 새 스키마**(다른 버전에서 열림): 읽기 전용으로 쓰고 저장하지 않음 + 안내.
- **개인정보**: 어떤 데이터에도 창 제목·창 안 글자·화면 이미지·사용자 이름을 넣지 않는다(이미지 파일 자체는 사용자가 고른 저장 폴더에만).
- **되돌리기 말풍선**: 지우기는 6초 [되돌리기](Tidy `undoToastModel.js` 시간 규칙).

| **U** 이동·크기 | S 고르기 → 끌기·모서리 | `Move`·`Resize` | Ctrl+Z |
| **U** 속성 | 고른 상태에서 색 키·Ctrl+휠 | `SetAttr` | Ctrl+Z |
| **U** 글자 고치기 | S → 더블클릭 | 입력 상자 다시 열기 → 끝나면 `SetAttr(text)` | Ctrl+Z |
| **D** 지우개 | D → 획 위 끌기 | 닿은 항목 `Remove` | Ctrl+Z |
| **D** 모두 | E | `Clear` + 말풍선 [되돌리기] | Ctrl+Z · 말풍선 |
| **D** 문서 | 나가기 | 보관 설정이면 `keptInk`로 옮김, 아니면 버림 | — |

실행 취소 단계는 최대 200개(넘으면 오래된 것부터 굳힘). 복사·저장(Ctrl+C/S)은 문서를 바꾸지 않는다(배경+판서를 합친 이미지 출력).

## 7. 보관 판서 (`keptInk`, 메모리)

## 12. 고정한 창 (`pinnedWindows`, 메모리 · P1 · Windows만)

창 핸들은 앱을 다시 켜면 뜻이 없어지므로 **파일에 저장하지 않는다**. 대신 창마다 `SetProp` 표시를 남겨, 비정상 종료 뒤에도 찾아서 풀 수 있게 한다. 항목에는 창 핸들·프로세스 ID·고정 시각만 두고 창 제목은 두지 않는다.

| 동작 | 계기 | 처리 | 화면 | 실패 |
|---|---|---|---|---|
| **C** 고정 | 고정 키 | 대상 고르기([02 §9](02-smart-logic.md)) → `HWND_TOPMOST` + 표시 → 목록에 추가 → 테두리 | 말풍선 "‘앱 이름’을 맨 위에 고정했어요" | 관리자 권한 창 → 안내, 목록 그대로 |
| **R** 목록 | 트레이 메뉴 열 때 | 살아 있는 창만 셈(`IsWindow`) | "고정한 창 모두 풀기 (n)" — 0이면 흐림 | — |
| **U** 테두리 따라가기 | WinEvent(이동·크기·최소화·숨김·cloaked) | 테두리 창 위치·보이기만 바꿈 | — | 사건이 끊기면 1초마다 위치 확인으로 대신 |
| **D** 풀기 | 같은 키 · 트레이 "모두 풀기" · 앱 끝냄 | `HWND_NOTOPMOST` + 표시 지우기 → 목록에서 빼기 → 테두리 지우기 | 말풍선 "고정을 풀었어요"(모두 풀기는 개수) | 창이 이미 닫힘 → 목록에서만 뺌 |
| **D** 저절로 | 고정한 창이 닫힘(`EVENT_OBJECT_DESTROY`) | 목록에서 빼고 테두리 지우기 | 없음 | — |
| **D** 정리 | 다음 시작 | `EnumWindows`로 screen-ink 표시가 남은 창 → 풀기 | 1개 이상이면 말풍선 "지난번에 고정한 창 n개를 풀었어요" | — |

설정(`settings.topmost`, 설정 구역): 테두리 켜기·색(테마 강조색 기본)·두께(2~8 px)·소리 켜기. 제외 앱 목록은 후속(PowerToys에는 있음).
