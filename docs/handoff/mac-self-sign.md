# 맥 자체 서명 — 만드는 사람·받는 사람 안내 (M-sign)

결정(2026-11-26): 맥 배포는 **자체 서명 인증서(무료)** 로 고정 서명한다. Apple Developer Program(연 99달러)은 사용자가 늘면 다시 본다.
고정 서명이 필요한 까닭: 임시(ad-hoc) 서명은 빌드마다 앱 신원이 바뀌어, 업데이트할 때마다 화면 기록·손쉬운 사용 권한이 풀린다.

---

## 1. 만드는 사람 — 인증서 한 번 만들기 (이 맥에서, 사람이 직접)

1. **키체인 접근** 앱 › 메뉴 **키체인 접근 › 인증서 지원 › 인증서 생성…**
2. 이름: `Shookshok Self Sign`(아무 이름이나 되지만 빌드 때 같은 이름을 쓴다)
3. 신원 유형: **자체 서명 루트** · 인증서 유형: **코드 서명** → 만들기
4. 확인: 터미널에서 `security find-identity -v -p codesigning` → 목록에 `"Shookshok Self Sign"`이 보인다.
5. 이 인증서(개인 키 포함)는 **이 맥 키체인에만** 둔다. 다른 맥에서 빌드하려면 키체인에서 `.p12`로 내보내 옮긴다(암호 걸기). 저장소·대화에 올리지 않는다.

## 2. 만드는 사람 — 빌드

```bash
APPLE_SIGNING_IDENTITY="Shookshok Self Sign" sh scripts/mac-build-dmg.sh
```

- 결과: `target/release/bundle/macos/Shookshok.app`, `target/release/bundle/dmg/Shookshok_…dmg`
- 스크립트가 지정 요구 사항(DR)을 `target/mac-dr.txt`에 남기고, 두 번째 빌드부터 "지난 빌드와 DR이 같아요"를 알려 준다.
- **[확인 필요]** 같은 DR이면 덮어 설치해도 권한이 남는지: 1차 설치 → 권한 켜기 → 2차 빌드(버전 올림) 덮어쓰기 → F1이 바로 되는지.

## 3. 받는 사람 — 처음 한 번 "그래도 열기"

공증(notarization)을 받지 않은 앱이라 처음 열 때 macOS가 막는다(macOS 15부터 Control-클릭 우회 없음).

1. dmg를 열고 **슉쇽**을 **응용 프로그램** 폴더로 끌어 놓는다.
2. 슉쇽을 연다 → "확인할 수 없어 열 수 없습니다" 창 → **완료**.
3. **시스템 설정 › 개인정보 보호 및 보안** 맨 아래 "슉쇽이(가) 차단되었습니다" 옆 **그래도 열기** → 암호 입력 → **열기**.
4. 처음 뜬 안내에서 **[화면 기록 켜기]** → 열린 칸에서 슉쇽을 켠다 → macOS가 묻는 **종료 후 다시 열기**(또는 안내의 [켰으면 다시 시작]).
5. 요소까지 잡으려면(선택) 첫 캡처 섬의 **손쉬운 사용 켜기** 칩 → 열린 칸에서 켠다(다시 시작 필요 없음).

**[할 일]** 3번 화면 그림 한 장(안내 페이지 `site/support/`에 넣을 것) — 사람이 받는 맥에서 찍는다(개인 정보가 안 보이게).
