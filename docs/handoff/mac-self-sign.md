# 맥 자체 서명 — 만드는 사람·받는 사람 안내 (M-sign)

결정(2026-11-26): 맥 배포는 **자체 서명 인증서(무료)** 로 고정 서명한다. Apple Developer Program(연 99달러)은 사용자가 늘면 다시 본다.
고정 서명이 필요한 까닭: 임시(ad-hoc) 서명은 빌드마다 앱 신원이 바뀌어, 업데이트할 때마다 화면 기록·손쉬운 사용 권한이 풀린다.

---

## 1. 만드는 사람 — 인증서 한 번 만들기 (이 맥에서, 사람이 직접 · 무료)

인증서 = "이 앱은 늘 같은 사람이 만들었다"는 도장. 한 번 만들어 두면 빌드할 때마다 같은 도장을 찍어, 업데이트해도 macOS가 같은 앱으로 보고 권한을 이어 준다. 맥 로그인 암호만 있으면 된다(돈·Apple 계정 필요 없음).

### 방법 A — 터미널 한 줄(쉬움)

1. **터미널** 앱을 연다(⌘ Space → "터미널").
2. 저장소 폴더에서 아래를 붙여 넣고 Enter:
   ```bash
   cd ~/Desktop/Architecture/screen-ink && sh scripts/mac-make-cert.sh
   ```
3. "키체인에 넣기"·"항상 신뢰" 때 **맥 로그인 암호** 창이 뜨면 입력한다(한두 번).
4. 끝에 `1 valid identities found` 와 `"Shookshok Self Sign"`이 보이면 완료.

### 방법 B — 화면을 따라 하기(키체인 접근 앱)

1. ⌘ Space → **키체인 접근** 입력 → 연다(macOS 27에서는 '유틸리티' 폴더에 없고 검색으로 연다).
2. 맨 위 메뉴 막대 **키체인 접근 › 인증서 지원 › 인증서 생성…**
3. 이름: `Shookshok Self Sign` · 신원 유형: **자체 서명 루트** · 인증서 유형: **코드 서명** → **생성** → (경고가 뜨면) **계속** → **완료**.
4. 왼쪽 위 **로그인** 키체인, 위쪽 탭 **내 인증서**(또는 **인증서**)에서 `Shookshok Self Sign`을 두 번 클릭.
5. **신뢰** 를 펼쳐 **코드 서명** 줄을 **항상 신뢰**로 바꾸고 창을 닫는다 → 맥 암호 입력. (건너뛰어도 서명은 되지만, 확인 명령에 "유효"로 안 나온다.)
6. 확인: 터미널에서 `security find-identity -v -p codesigning` → `"Shookshok Self Sign"`이 보이면 완료.

### 주의

- 인증서(개인 키 포함)는 **이 맥 키체인에만** 둔다. 다른 맥에서 빌드하려면 키체인 접근에서 그 인증서를 `.p12`로 내보내(암호 걸기) 옮긴다. 저장소·대화·메신저에 올리지 않는다.
- 다시 만들면 도장이 바뀐다 → 그 뒤 첫 업데이트에서 권한을 한 번 다시 켜야 한다. 한 번 만든 것을 계속 쓴다.

## 2. 만드는 사람 — 빌드

```bash
APPLE_SIGNING_IDENTITY="Shookshok Self Sign" sh scripts/mac-build-dmg.sh
```

- 결과: `target/release/bundle/macos/Shookshok.app`, `target/release/bundle/dmg/Shookshok_…dmg`
- 스크립트가 지정 요구 사항(DR)을 `target/mac-dr.txt`에 남기고, 두 번째 빌드부터 "지난 빌드와 DR이 같아요"를 알려 준다.
- **[확인 필요]** 같은 DR이면 덮어 설치해도 권한이 남는지: 1차 설치 → 권한 켜기 → 2차 빌드(버전 올림) 덮어쓰기 → F1이 바로 되는지.

## 3. 받는 사람 — 처음 한 번 "그래도 열기"

공증(notarization)을 받지 않은 앱이라 처음 열 때 macOS가 막는다(macOS 15부터 Control-클릭 우회 없음).

1. dmg를 열고 **슉쇽**을 **응용 프로그램** 폴더로 끌어 놓는다.
2. 슉쇽을 연다 → "확인할 수 없어 열 수 없습니다" 창 → **완료**.
3. **시스템 설정 › 개인정보 보호 및 보안** 맨 아래 "슉쇽이(가) 차단되었습니다" 옆 **그래도 열기** → 암호 입력 → **열기**.
4. 처음 뜬 안내에서 **[화면 기록 켜기]** → 열린 칸에서 슉쇽을 켠다 → macOS가 묻는 **종료 후 다시 열기**(또는 안내의 [켰으면 다시 시작]).
5. 요소까지 잡으려면(선택) 첫 캡처 섬의 **손쉬운 사용 켜기** 칩 → 열린 칸에서 켠다(다시 시작 필요 없음).

**[할 일]** 3번 화면 그림 한 장(안내 페이지 `site/support/`에 넣을 것) — 사람이 받는 맥에서 찍는다(개인 정보가 안 보이게).
